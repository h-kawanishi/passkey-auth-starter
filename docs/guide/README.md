## 書くときの約束（この解説を直す人へ）

- 各章の先頭は「# 見出し」1 つだけにする。図は ```` ```mermaid ````、コードは言語付きのフェンスにする
  （jumpstack.co.jp 側の変換スクリプトがこの形を前提にしている）
- コードを引用するときは、1 行目に `// 出典: ファイル:開始行-終了行` を書き、実物と 1 文字も変えずに写す。
  途中を省くときは `// …（略）` の行を入れる。`test/unit/guide.test.ts` が実物と照合する
- 専門用語は初出で一文で説明する。「なぜ」を先に書く。「完全に安全」のような言い切りをしない
